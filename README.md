A clean, modern, fully responsive personal portfolio designed to highlight an engineering mindset, scalable backend systems, and high-impact AI products. Tailored specifically with a competitive FAANG candidate hierarchy in mind.

## ✨ Features
- **Executive Structure:** Optimized content flow prioritizing "The Vision", Engineering Philosophy, Impact, and highly-technical Case Studies.
- **Modern Glassmorphism:** Premium UI featuring transparent frosted glass cards (`.glass-card`), ambient pulsing orbs, and incredibly slick animated glowing borders that rotate on hover.
- **Blazing Fast:** Zero build-step architecture. Pure HTML heavily customized via Tailwind CDN. 
- **Functional Contact Form:** Fully integrated using FormSubmit without needing a dedicated backend.

## 💻 Local Setup
Since this project uses a pure, highly-optimized frontend architecture:
1. Clone the repository:
   ```bash
   git clone https://github.com/Priya-173github/aiportfolio.git
   ```
2. Navigate into the folder and simply drop `index.html` into your favorite web browser! (No `npm install` necessary).
